## 这是什么

一个 A 股全市场扫描器，用五个互相独立的维度找「主力吸筹」的迹象：

| 维度 | 看什么 | 逻辑 |
|---|---|---|
| **C1 量增价平** | 低位 + 横盘 + 放量 | 价格不动但成交量上来，通常意味着有人在吸 |
| **C2 筹码集中** | 股东户数逐期下降 | 散户口数在减少，筹码在向少数人集中 |
| **C3 杠杆资金** | 融资余额净增 | 杠杆资金在加仓，且有"过热"标记 |
| **龙虎榜** | 上榜席位与净买 | 有大资金痕迹 |
| **情绪周期** | 涨停/跌停家数 | 判断当下是安全期还是退潮期 |

**硬门槛：五维里至少三维同时命中**，低于三维不出结论。

输出的是「判断卡」：命中了哪几维、每维的具体数值、置信度、以及一句可以被质疑的结论。

## 为什么用多维交叉

单一信号容易骗人。

放量可能是吸筹，也可能是出货；股东户数下降可能是集中，也可能是散户认赔离场。
**五个独立来源同时指向同一个方向，才值得看一眼。**

这套设计的取舍是：宁可漏掉，不要错杀。

## 数据源

- **K 线**：腾讯行情接口（主），东财（备份，单只失败时降级）
- **股东户数**：交易所披露的 CSV，按报告期归档
- **融资余额**：沪深交易所披露的 CSV
- **快照**：实时行情接口

全部免费源，不需要付费账号。数据文件需要你自己准备并放进 `data/`。

## 目录

```
├── scan.py            全市场扫描：拉数据、算 C1/C2/C3、输出结果
├── check_signals.py   单只股票的信号明细
├── engine.py          引擎层：五维聚合、置信度、判断卡（参考实现）
└── LICENSE
```

## 用法

```bash
pip install akshare pandas requests

python scan.py quick    # 每日用：快照粗筛 → 精筛
python scan.py scan     # 只扫描，基于已有缓存
python scan.py update   # 全量更新 K 线缓存（首次用，很慢）
```

## 关于 engine.py

`engine.py` 是从一个本地面板项目里抽出来的，里面写死了相对目录结构（`data/`、`../07-模拟盘跟踪/`、`../04-情绪与轮动/`）。

**直接跑会因为找不到路径而失败，你需要改成自己的目录。** 它的价值在于展示五维怎么聚合、置信度怎么算、判断卡长什么样，不是拿来即用的成品。

## 一些实现上的坑（都写在代码注释里）

- 东财接口对频繁调用会临时封 IP，所以全量走腾讯源
- 上市不足 290 个交易日的股票直接排除（数据不够算 250 日窗口）
- ST、退市、北交所（4/8/920 开头）排除
- 近 20 日有停牌的不参与计算
